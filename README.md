# AI-Vision Smart Navigator – Smart Assistive Stick for the Visually Impaired

## 📌 Project Overview

The **AI-Vision Smart Navigator** is an Arduino-based assistive device designed to help visually impaired individuals navigate their surroundings more safely and independently.

The system uses multiple sensors to detect obstacles and water surfaces. It provides real-time alerts through a buzzer and vibration motor, helping users identify potential obstacles in their walking path.

## 🎯 Objectives

- To develop an affordable smart navigation stick for visually impaired individuals.
- To detect nearby obstacles using an ultrasonic sensor.
- To identify water surfaces using a water sensor.
- To provide immediate alerts through sound and vibration.
- To improve mobility, safety, and independent navigation.

## ⚙️ Working Principle

1. The ultrasonic sensor continuously measures the distance between the stick and nearby obstacles.
2. When an obstacle is detected within the predefined distance, the Arduino activates the buzzer and vibration motor.
3. The water sensor detects the presence of water on the walking surface.
4. When water is detected, the system alerts the user through sound and vibration.
5. The Arduino processes sensor inputs and controls the alert mechanisms in real time.
